# Contributing

One entry per pull request.

- **Format:** `- [Name](URL) — One-line description. *License or free note.*`
- **Bar for entry:** open-licensed content, open-source software, or genuinely
  free resources. No pirated book text, no paywalled content presented as free.
- **Verify the link** resolves before submitting. Dead links are removed by
  the weekly link check.
- **Say the license** if you know it (CC-BY-4.0, ORC, OGL, MIT, CC0…). It
  matters double here: this list is the corpus map for the D&D-only model in
  [MODEL.md](MODEL.md), and only clean-license entries can become training
  sources.
- Put the entry in the right section, roughly alphabetical within it.
- Duplicates across sections are not allowed — list once, cross-reference
  with an anchor link if needed.
